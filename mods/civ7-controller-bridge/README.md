# Mac 手柄支持修复 · Mac Controller Support Fix

[English](README-en.md) · 版本 0.1.5

修复 Mac 上 Xbox 手柄能操作《文明 VII》菜单，却无法操作世界地图的问题。左摇杆控制地图光标，并可带动镜头跟随；右摇杆平移镜头。左右摇杆方向可以分别设置。保留 RB（右肩键）轮盘操作，0.1.5 补充主菜单及轮盘对摇杆 HOLD 连续输入的兼容。

## 安装和设置

订阅 Steam 创意工坊版本并等待下载，重新启动游戏，在主菜单“附加内容”确认模组已启用。Steam 的本游戏控制器设置需**启用 Steam 输入**，使用官方 Xbox 布局。

主菜单或暂停菜单 → **选项 → 附加内容 → Mac 手柄支持修复**：

- **启用手柄兼容**：默认开启；关闭后恢复原生输入方式。
- **翻转左摇杆上下**：默认关闭，取消 0.1.2 的强制翻转；影响地图光标及随它移动的镜头。如果仍与预期相反，切换这一项并确认。
- **翻转右摇杆上下**：只调整右摇杆，默认开启；升级保留原来的选择。
- **显示调试栏**：默认关闭；需要排查问题时再打开。隐藏调试栏不影响手柄功能。

点击“确认”保存设置；取消会丢弃本次修改。界面随游戏语言显示简体中文或英文。已安装旧版 Controller Bridge 时，原有设置继续保留，内部 Mod ID 没有改变。

手动安装版和工坊版只保留一份，避免重复加载。手动安装目录为 `~/Library/Application Support/Civilization VII/Mods/civ7-controller-bridge/`，清单应位于该目录第一层。关闭模组可在主菜单“附加内容”操作，重启后生效。

## 按键

| 按键 | 地图中的行为 |
| --- | --- |
| 左摇杆 | 移动六角格光标，镜头可随光标移动；上下方向可单独设置 |
| 右摇杆 | 平移镜头 |
| 十字键 | 普通地图且界面无焦点时移动地图光标；选中单位时导航单位按钮 |
| A / B | 原生确认／取消 |
| LT / RT | 每按一次缩小／放大一级 |
| 右摇杆按下 | 将地图光标移回镜头中心 |
| RB（右肩键） | 普通地图打开轮盘；选中单位或进入菜单时保留原生“下一项”导航 |
| X | 保留普通地图轮盘的备用按键；选中单位时进入移动选点 |
| Y | 原生“下一步”；待办完成后可能结束回合 |
| 菜单键 | 原生暂停菜单 |
| LB、左摇杆按下 | 原样交给游戏；未补全单位循环或全部原版快捷键 |

暂停、设置、科技等界面打开时暂停地图兼容，菜单操作保留。城市等 Dual 视图和原生软鼠标模式暂不接管。十字键在没有连续方向事件时最多持续约 0.75 秒，松开再按可继续；这是避免断连后持续移动的保护。缩放是每次按下一步。

## 验证范围

早期版本已收到 Mac + Xbox 蓝牙手柄“可以使用”的用户反馈。0.1.3 左摇杆方向已获用户实测确认。用户也反馈 RB 轮盘可以打开，但主菜单及轮盘的左摇杆不响应。0.1.5 通过 64 项离线测试，包括原版菜单槽和轮盘面板对 HOLD 连续输入的回放，以及原有地图、设置和备份工具检查。按钮中文字体已在独立浏览器中使用游戏字体验证。

主菜单和轮盘会忽略 HOLD 类型的模拟导航，0.1.5 只将菜单中的 nav-move/HOLD 转换为 UPDATE，保留角度和原有分发。未采集到用户故障现场的原始输入，因此这是一项针对已复现兼容缺口的修补，是否解决用户这次故障仍待确认；不会据离线测试声称实机已修好。本次没有开启游戏验证。原版教程或当前视图不允许轮盘时，仍遵守游戏本身的限制。其他手柄、多人模式、城市视图和完整快捷键未完成验证。它依赖 Steam/游戏已经能收到菜单手柄输入；不能解决系统完全识别不到手柄的问题。其他改写输入模式的模组可能冲突。

开始测试或加载测试存档前，请完整备份整个 `Saves` 目录，包括 `auto`、`auto/prev` 和 `quick`；确认备份完整，使用测试副本，不覆盖正式战役存档。模组声明 `AffectsSavedGames=0`，不新增游戏规则或存档实体；手柄确认操作仍会正常影响当前对局。

## 排查

先在附加内容打开“显示调试栏”，确认后返回地图。观察状态是否为“地图接管中”，以及左／右／十字计数是否随输入增加。计数是输入事件数，不是按键次数。开启调试后，主菜单或游戏面板中的摇杆输入会限量记录到 UI.log，前缀为 `[ControllerBridge:MenuInput]`。若菜单仍不响应，开启后分别推动左右摇杆和十字键即可留下诊断记录；不自动确认或执行菜单选项。

反馈时说明游戏版本、手柄型号、Steam 布局、所在界面、按键和实际现象。日志位于 `~/Library/Application Support/Civilization VII/Logs/UI.log`，搜索 `[ControllerBridge]`。需要恢复原生输入时关闭“启用手柄兼容”。
