文明 VII：垃圾时间（Garbage Time）0.1.4

使用入口
1. 游戏内：选项 → 附加内容 → 垃圾时间。
2. 定居点：打开生产面板，勾选“垃圾时间”；“配置”打开本城设置。
3. 全部自动化默认关闭。设置页面修改后点“确认变更”；本城窗口点“保存”。

资源分配
开启“资源分配垃圾时间”后，每个己方回合自动调用资源规划 Mod 的“按倾向分配”，无需打开面板。先在资源面板中点击产出图标设置定居点倾向。使用同一套收益计算、分配请求和失败撤回流程，不会自行建立贸易路线或替你选择倾向。
资源锁定时等待解锁；同回合不会因重复事件或读档再次分配。每次都会重新读取当前存活定居点和记住的倾向。默认只使用空闲资源、不包含骆驼；附加内容里可分别打开“包含骆驼”“包含已分配资源”。设置页开启或玩家/回合变化时停止继续发送资源请求，等待本轮撤回结束后再恢复其他自动化；中断时不会误确认其他回合的资源提醒。
本功能需要已启用 civ7-resource-planner（资源规划）及其 Resource Re-sorts 依赖；未启用时其他垃圾时间功能仍可独立使用。资源分配使用资源规划 Mod 的既有换算规则，定居点人口权重与它分别配置。

军事
“军事垃圾时间”有两种互斥方式：进入最近可达的己方定居点，或集结到指定定居点。抵达后休眠。城市中心无法进入时使用该定居点的可通行地块；已经在目标定居点范围内的单位就地休眠。装载在指挥官内的单位随指挥官移动。
按实际路径预计回合数及路径长度比较远近。无法到达的目标跳过。不会主动攻击、宣战，也不以进入外国军事区域的方式执行集结。目标城市丢失时暂停指定集结。
关闭开关后撤销本 Mod 尚未完成且目标仍匹配的移动命令；已经到达并休眠的单位保留休眠状态。
空军使用原版转场操作，目的地必须是目标定居点中可驻扎的基地；没有合法基地时保持原位。不可移动的固定航空基地保持原位。

定居点
每个定居点独立开启。默认继承全局权重和快乐度阈值，也可以勾选独立配置。
金 / 粮 / 科 / 文 / 锤 / 笑脸默认：1 / 2 / 4 / 4 / 4 / 8。
科研城：1 / 2 / 8 / 4 / 4 / 8。
金币城：4 / 2 / 4 / 4 / 4 / 8。
文化城：1 / 2 / 4 / 8 / 4 / 8。
笑脸为动态权重：按分配前该定居点的每回合净幸福度判断，为负时使用配置值（默认 8），为正或为 0 时实际权重为 0。笑脸增量为负时扣分。单城配置会显示当前实际折算权重。
例如只有科研 +3 和笑脸 +2 两种候选时，幸福度为负时分别得 12 分和 16 分；幸福度非负时分别得 12 分和 0 分。
旧版保存的五项权重会自动补上笑脸 8，其他自定义值保留。全局和单城都可以调整负幸福度时使用的笑脸权重。
权重可设为 0—100 的整数；快乐度阈值为 -100—100，默认 0。
待分配人口出现时，对合法扩张地块和专家岗位的预计新增净收益评分；专家维护费计入净收益。当前以及预计分配后的每回合净快乐度都必须严格高于阈值。候选收益无法可靠读取时不提交该分配。
动态笑脸评分不会绕过上述门槛。例如阈值 0 时，负幸福度仍暂停分配；将阈值设为更低的负数后，满足门槛的候选才会按包含笑脸的分数排序。
这里的快乐度指“每回合净快乐度”，不是累计庆典进度。低于或等于阈值的垃圾时间定居点会在右下角显示独立行动提醒；点击提醒打开该定居点。Mod 不会自行建设快乐度建筑。
城市生产队列空闲时，以科研与文化权重为分数，始终选择分数最高且可用的原版科研/文化项目。科研 8、文化 4 时持续选择科研；科研 4、文化 8 时持续选择文化；同分固定优先科研。过去生产过多少次不影响选择。最高分项目不可用时选择另一项；权重为 0 的项目不安排，两个权重均为 0 时不安排项目。已有队列不会被清空，新规则在队列空闲时生效。城镇可自动分配人口；原版科研/文化项目仅供城市使用，因此城镇保持原有专精。

宝藏船
自动前往最近可达的本土定居点，按游戏本土/远方土地判定。进入本土定居点范围后，当原版允许“卸载货物”时自动兑现宝藏，获得原版奖励并消耗该宝藏船。沿用宝藏船垃圾时间开关；关闭时不会自动兑现。

宗教
传教士前往最近可达、尚未信奉本宗教的定居点。分别设置本国、城邦、其他国家三个范围，默认仅本国。
同时检查城市和乡村的宗教，避免城市中心已转换、乡村未转换时卡在中心。仅调度信奉本宗教且有传播次数的传教士；抵达后原版允许时传播。独立势力营地不算城邦或其他国家。

科技与文化
分别开启。保留当前研究，在需要新研究时选择可用的未完成节点；优先预计用时短的普通科技、市政及精通，最后处理可重复的未来科技/市政。文明专属市政在可研究时也会纳入。
不会自动结束回合、选择政策、时代转换选项、领袖属性或外交决策。

保存与适用范围
全局默认保存在原版附加内容共享设置中，仅修改本 Mod 的命名空间。
开关、集结目标、定居点配置和项目计数跟随当前存档保存，并按玩家及时代隔离。新存档和新时代需要重新主动开启。开启后请正常保存游戏，以便下次读档继续使用。
当前版本仅在单人游戏的本地玩家回合执行自动化。菜单和需要用户决策的界面打开时暂停操作。大量单位初次计算路线会分批进行。
已在 Windows Steam 版 1.5.0（1311346）DX12 测试；详情见 VALIDATION-zh-CN.txt。

安装
退出游戏，将安装包内整个 civ7-garbage-time 文件夹放入：
%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VII\Mods\
确保垃圾时间启用，然后重新启动游戏。不要把 ui/text 单独散放到 Mods 根目录。
卸载时先关闭各项自动化并保存，再退出游戏，移走 civ7-garbage-time 文件夹。

开发
这是通过原生 UI、原版合法性检查和 sendRequest 调度的 UI Mod；不修改游戏核心文件或数据库规则。
源码包包括 tests；安装 Node.js 后在项目目录运行 node --test tests/*.test.mjs。

macOS 安装与验证
Steam 工坊订阅会自动下载。手动安装目录为 ~/Library/Application Support/Civilization VII/Mods/；不要同时加载同 ID 的手动版和工坊版。
2026-10-18：Apple Silicon Mac / Metal 通过仓库 324 项自动测试，游戏成功加载模组并进入主菜单。Mac 对局内操作尚未完整验证。
