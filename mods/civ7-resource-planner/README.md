# 资源规划 · Resource Planner 1.1.0

[English guide](README-en.md)

为当前已安装的 **Resource Re-sorts 3.0.2** 增加资源规划功能。适配并实机检查于《文明 VII》**1.5.0 (1311346)，Windows DX12**。

## 语言

当前开发源码提供英文与简体中文，跟随游戏文字语言设置；其他语言使用游戏原生英文回退。按钮、工具提示、分组、倾向、进度、错误和模组介绍均接入原生翻译系统，不新增语言开关。2026-10-23 的语言更新仅在本地完成，尚未替换安装版或更新工坊，也未做本轮实机验收。

## 使用

打开原来的资源／贸易面板：

- 左侧六个图标按金币、粮食、科技、文化、生产力、幸福度排序。首次使用默认幸福度降序；再次点击同一图标反转顺序，随后记住排序设置。
- 只在打开资源页、点击排序图标或手动重排时计算顺序。资源调整和自动分配过程中，收益与空槽继续更新，定居点顺序保持稳定；自动分配结束后也不自行重排。
- 右侧依次显示“城市”“城镇”“未连入贸易网络”。只在组内排序，每组标题可折叠展开。离网城市或城镇只归入最后一组。
- 城市资源标题旁的“填充”：先给缺幸福度的城市补充，再处理城镇。城镇资源（通用）标题旁的“填充”：只处理城镇，不从城市抽走资源。达到非负后停止继续堆叠纯幸福度资源。
- 点击定居点的一枚产出图标，记录该定居点倾向并立即尝试填入相关资源。高亮图标和“倾向：…”显示选择；点击旁边的 × 清除倾向。
- 已选中资源时，点击定居点产出图标优先放置该资源，不触发倾向分配。右键／Esc 先取消选中和拖拽；没有选中资源时再关闭面板。
- 左上“按倾向分配”同时考虑所有已设置倾向的定居点及其空槽。
- “包含骆驼资源”允许计算骆驼的净扩槽收益；“包含已分配资源”允许重排现有资源。两项每次打开面板默认关闭；关闭时保留相应的已分配资源。勾选同时作用于本面板的填充操作。

倾向按地图种子、玩家、定居点原始拥有者及位置记忆，可跨面板、重启和读档保留。同一地图的旧存档共用这些界面偏好，偏好不写入游戏存档。

## 收益规则

金币／粮食／科技／文化／生产力／幸福度的权重为 **1／2／4／4／4／8**。幸福度只计算负数到零之间的改善：例如 -2 加 6 幸福度计 16 分，原本非负则计 0 分。因此不会为了溢出的幸福度继续占槽。影响力没有用户指定的换算权重，按 0 计入总分。

同倾向定居点并非按列表先后抢资源。程序先用最大权重匹配处理资源归属和容量，再比较完整定居点收益，改善单项移动及资源互换。百分比加成使用扣除支出前的基础产出；仓库／水域建筑等标签加成使用实际未损坏建筑数量；城市、城镇、首都和远方领土条件分别判断。不同产出混合的资源按六项加权总收益比较。

骆驼不消耗已有空槽，每份净增加 2 个可用槽位，仅在扩槽后能够提高总收益时才会使用；勾选两个开关后也能比较迁移已分配的骆驼。单位／建筑专用生产加成按当前建造队列是否适用计分。

非线性组合采用匹配后迭代改善，不宣称穷举了所有组合。无法识别的第三方资源条件或全帝国持有加成不冒充定居点插槽收益；合法性最终以游戏引擎为准。没有适用资源、空槽、有效倾向或正收益时，保持原状并显示原因。

## 安装和兼容

依赖原版 `base-standard` 和 `bz-re-sorts`；请保持 **Resource Re-sorts** 启用。

手动安装时先退出游戏，将整个 `civ7-resource-planner` 文件夹复制到：

```text
%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VII\Mods\
```

此 Mod 为 UI 扩展，`AffectsSavedGames=0`。没有覆盖 Steam 工坊文件，也没有修改游戏数据库；卸载此文件夹即可恢复原 Resource Re-sorts 面板。改变同一资源页面的其他 Mod 可能发生覆盖冲突。游戏或 Resource Re-sorts 升级后应重新检查页面兼容性。

分配仍遵守游戏的回合锁定、资源类别、贸易网络和可用槽位规则。操作逐项等待游戏确认，失败时尝试撤回本次已经发出的调整。面板会显示失败或未完全恢复的提示。

## 2026-10-20 Mac 修复验证（尚未更新工坊）

倾向规划改为分段计算，关闭资源页面可以取消尚未提交的规划；规划内部复用城市资源列表和效果，减少重复扫描。92 份资源、36 个定居点的人工压力用例从离线计算约 28.5 秒降至约 4.2 秒，期间可处理界面输入。游戏内同一压力用例总耗时约 14.6 秒（含游戏定时器调度），期间处理 507 次界面定时任务，最大间隔约 31.5 毫秒。18 项自动测试通过，100 组固定种子对照与旧算法的分配结果一致。

本版继续沿用 Resource Re-sorts 3.0.2 的资源模型和拖拽组件。Mac 实机已验证一份空闲香料拖入首都；间歇性拖拽失灵的具体触发条件仍待复现，不能据此宣称所有交互问题都已修好。

Mac 实际对局完成一次 4 份资源重新分配，约 1.1 秒后状态恢复为空闲。测试结束前电脑锁屏，修改后最后一次鼠标拖拽复测未完成。
