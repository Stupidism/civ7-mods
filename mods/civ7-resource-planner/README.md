# 更好的资源界面

[English](README-en.md) · 版本 **1.5.0** · 2026-11-09

在同一资源页面里查看定居点产出、标记倾向、补足幸福度并安排资源。支持简体中文与英文，跟随游戏文字语言。内部 Mod ID 沿用 `civ7-resource-planner`，保留已有偏好。

## 安装与兼容

[Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3822254182)。订阅更新后重启游戏，在附加内容中确认启用。不要同时启用手动副本和工坊副本。

这是独立版本，**不再需要另外安装 Resource Re-sorts**。请停用另一个覆盖相同资源／贸易页面的 Mod，包括单独的 Resource Re-sorts，以免覆盖冲突。页面派生自 beezany 的 Resource Re-sorts 3.0.2，归属见 [NOTICE.md](NOTICE.md)。无需额外安装行动顺序调整；旧版 Action Order Adjustments 应停用。

## 查看、排序和整理

城市、城镇、未接入贸易网络的定居点按上下三组显示。左侧是主要操作，上方是靠左的两行排序与资源高亮，右侧是未分配资源。每个定居点内，左边是产出与倾向，右边是资源槽位。

点击排序图标按对应指标排序，再点切换升降序。调整资源期间顺序保持不变，仅主动排序或重新打开时计算。铁路和工厂排序仅在现代时代显示；高亮按当前资源效果提供图标。悬浮或手柄聚焦会解释操作。**一键整理**只整理卡槽顺序，不改变资源归属。

## 倾向与分配

每个产出图标独立循环：普通 → 倾向 ×2 → 避免 ×0 → 普通，可同时选择多项。倾向以绿色边框和内侧上三角表示，避免以红色边框和内侧下三角表示；当前焦点使用金色背景。标记后点击 **按倾向分配** 才执行。避免只让该项评分为零，并不禁止手动放入，也不忽略混合资源的其他收益。

尚未手动修改时，默认倾向选取每种产出裸值最高且为正的定居点，同分共享。裸值排除资源加成和百分比加成。任意手动修改或清除后，停止自动更新默认倾向。**重置倾向**恢复默认计算；单个定居点的清除图标只清除该处标记。

可选择包含骆驼和已分配资源，开关会保留。金币／食物／科技／文化／生产力／幸福度的基础权重为 1／2／4／4／4／8，倾向再乘2，避免乘0。影响力目前不计转换收益。按倾向分配只给幸福度从负数补到0的部分计分；提高到5或20由单独的幸福度操作处理。

分配比较合法定居点的加权收益，考虑槽位、资源类别、贸易连接及骆驼增加的容量；非线性组合采用迭代改进，不保证全局最优。游戏锁定、无合法位置或无正收益时不强行分配。每次操作等待确认；取消、切换上下文、锁定或超时会停止后续请求，已确认部分保留；恢复不完整时显示结果。

## 幸福度

选定城市优先或仅城镇，再点击 **补足幸福度**。定居点目标可选0或5，城市目标可选0或20，默认都是0；城市取两项目标的较大值。仅城镇模式不处理城市。改变选项不会立即分配，槽位或资源不足时可能达不到目标。

## 生产进度与盐

资源页的城市标题显示正在训练、建造或执行的项目，以及已投入／所需产能；未知进度不伪造为0，城镇不显示无意义的“不生产单位”。生产队列内部界面由更好的定居点界面负责。

盐等条件资源只有在当前队首满足对应条件时才计入收益；盐对应训练单位。全部生产力评分统一比较调整前后：

`可用生产价值 = min(当前项目最终产能, 剩余需求) + max(百分比前基础产能 − 剩余需求, 0)`

例如基础60、加成50%、剩余80时，再加2基础锤计0；剩余30时再加2基础锤计2。这样排除加成产生的浪费区间，同时保留基础溢出的边际价值。百分比与条件加成也按此比较，最后再乘产能权重和倾向。未知剩余需求沿用未截断估值。原始产出显示不受评分截断影响。这是分配估值规则，并非对原版全部溢出机制或未来队列的精确模拟。

## 提醒与输入

资源提醒只考虑合法空槽与可用资源；损坏资源不计为可用资源，只有盐等当前不生效的条件资源时不催促分配。可在左栏开关资源空槽提醒。普通关闭把未完成操作放到本回合后面；右上角跳过按钮或长按页面跳过键（默认X）一秒跳过本回合，下回合重新检查。不会自动结束回合。

鼠标可点选／放置；Shift 拖动同类资源，中键快捷填入同类资源或卸下一份；右键先取消当前选择。

手柄有四个操作区：主要操作、排序与高亮、定居点倾向、资源槽位与未分配资源。左摇杆或方向键选择区域，A确认进入，左右扳机切换；B先取消资源，再退出编辑／操作区，最后关闭。拿起资源时，非放置操作禁用。资源聚焦时快捷动作可批量处理同类资源；拿起已分配资源后可用移除动作退回未分配。对已有资源的槽位可交换，换回资源不能放入原处时退回未分配。设备图标和当前动作以游戏底栏提示为准。完整实体手柄验收尚未完成。

保留垃圾时间的资源自动分配接入；需另行启用垃圾时间的对应选项。偏好属于界面设置，同一地图旧存档会共用，操作仍改变当前局的实际资源分配。
