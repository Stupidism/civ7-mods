[h2]使用 / Usage[/h2]
城市、城镇与离网定居点上下分组。点击排序或关闭重开时重算；调整资源期间顺序稳定。一键整理只整理卡槽，不改变归属。
点击产出图标循环普通→倾向→避免，可多选；点击“按倾向分配”执行。可包含骆驼和已分配资源，选项保留。默认倾向按最高正裸产出选取，手动修改后停止自动更新；重置恢复。幸福度填充可选城市优先或仅城镇；城市取两项目标的较大值，资源或容量不足时可能达不到目标。
手柄用左摇杆／方向键选择四区、确认进入、左右扳机切换；取消逐层返回。区域包括主要操作、排序高亮、倾向、卡槽与未分配资源。原生按键图标与说明见底栏。关闭把未完成操作延后；长按页面跳过键（默认X）一秒跳过本回合，下回合再检查。

Settlements are stacked in city, town and disconnected groups. Sort explicitly or reopen to recalculate; assignment keeps ordering stable. Tidy changes card order only. Cycle yield marks and press Assign by preference to apply. Optional Camels and assigned-resource rearrangement persist. Defaults favor the highest positive bare yields until manually edited; Reset restores them. Fill happiness supports Cities first or Towns only and targets0/5 for settlements,0/20 for cities, subject to available resources and capacity.
Controller areas use stick/D-pad selection, Confirm to enter, triggers to switch and layered Cancel. Device-specific hints appear in the bottom tray. Closing defers unfinished work; holding the page skip action (default X) skips this turn only.

[h2]评分与限制 / Scoring and limits[/h2]
金币／食物／科技／文化／生产力／幸福度权重1／2／4／4／4／8，倾向再×2，避免×0；按倾向分配只给负幸福度补到0计分，单独填充使用所选目标。影响力目前不计转换收益。
产能价值=min(当前项目最终产能,剩余需求)+max(百分比前基础产能−剩余需求,0)。例如基础60、加成50%、剩余80，新增2基础锤计0；剩余30时计2。未知进度保留未截断估值。这是分配估值规则，不是原版全部溢出或未来队列的精确模拟。
Gold/Food/Science/Culture/Production/Happiness weights are1/2/4/4/4/8; preferences multiply their contribution. Production value is min(final current-item rate, remaining cost) + max(pre-percentage base − remaining cost,0). At base60 with+50% and80 remaining,+2base scores0; at30 remaining it scores2. Unknown progress keeps the uncapped estimate. This is an allocation policy, not full native overflow/future-queue simulation.
游戏仍决定回合锁定、资源类别、网络和槽位合法性。非线性分配不保证全局最优；不支持的第三方条件不冒充收益。偏好跨重启和读档保留，同一地图旧档共用界面偏好。保留垃圾时间的资源分配接入。
Native locks, resource classes, trade networks and capacity still apply. Allocation is not guaranteed globally optimal. Unsupported third-party conditions are not counted. UI preferences persist and are shared across saves of the same map. Garbage Time integration is retained.
