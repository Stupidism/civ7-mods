0.6.0 开发稿（2026-10-22）
原地集中火力已接入游戏数据库临时战斗力效果，兼容已有存档；实际验证与边界见 VALIDATION-zh-CN.txt。未发布工坊。

新增六个独立开关，默认开启：
- 部署后保持指挥官焦点：只要还有已收纳军事单位就保留军队选择；不计平民和侦察单位。
- 自动选择下一个可派出单位：检查剩余移动力及原版合法退出格，并给当前头像加金色边框；与保留指挥官焦点独立。派出后腹内头像按实际名单刷新，已派出的头像移除；关闭自动选择也会刷新。
- 攻击后选择下一个远程单位：手动攻击完成后，选择同一指挥官范围内、同类型、可原地攻击可见敌人的下一个单位。只选择，不自动攻击。
- 原地火力参与者高亮：进入集中火力后，指挥范围内的远程编队默认全选，持续显示金色边框。悬停敌人时，仅能原地攻击它的已选单位显示原生红色攻击箭头；移到空地或友军时，箭头消失，金框和选择保留。
- 原地火力手动排除：依赖高亮开关。先直接点友军取消／恢复编队选择；取消后金框消失，再点同一单位可恢复。悬停敌人看攻击箭头，点击敌人开火。不弹窗、不先锁定敌人；只影响本次齐射。
- 增援指挥官快速切换：默认预览最近的己方指挥官，包含当前不可增援者；LB/RB、键盘上下、鼠标滚轮、面板上一个／下一个均可切换。不可增援者禁用确认，不自动转投别的指挥官。

集中火力
沿用原来的集中火力按钮。先在地图上选择编队，再悬停敌人查看实际可攻击者；点击敌人确认原地齐射。金框表示编队选择，箭头表示对当前目标能实际开火的子集；使用原生取消操作退出。按距离从远到近逐发执行，每发完成后重新检查；目标消失即停止。不发送移动命令，不额外增加移动力或攻击次数。
发动前指挥官至少需要 1 点移动力；第一发实际开火后，清空该指挥官剩余移动力，整轮只结算一次。预览、取消或没有实际开火不扣移动力。移动上限不变，其他单位的移动力不受该结算影响。
每发仅在结算期间补回集中火力的战斗力：读取游戏基础值、射击单位实际收到的弹幕等加成、已装备纪念物的加成。射后关闭，取消后续齐射不会让加成常驻。初始化或加成计算失败时不发射，不降级成无加成攻击。
这是单人游戏功能；多人游戏沿用原版集中攻击。未改变近战协同攻击或空军集中攻击。自定义 Mod 若另加特殊触发奖励，不能保证等同原版集中攻击事件；本功能保留的是战斗力加成。

用途
减少弓箭手及指挥官的重复操作。除集中火力的临时战斗力效果外，加入、退出、攻击和增援命令仍由原版规则检查；不增加移动力或攻击次数。

原有六项功能（规则更新）
1. 选中有移动力、尚可攻击且存在可攻击的可见敌人的远程单位，自动进入原版攻击选格模式。攻击优先于加入。近战单位保留原版移动/攻击模式。
2. 没有上述攻击目标、且同格或相邻一格存在可加入的己方指挥官，自动进入原版加入模式；再选择指挥官即可。
3. 在默认操作状态，仅当己方指挥官所在格还有其他己方军事单位时，右键优先执行加入；没有其他军事单位则正常移动。暂时不能加入时提示并阻止移动/换位。已在攻击、加入或退出选格模式时，第一次右键仍用于取消；回到默认操作后再次右键才执行加入。主动使用原版“移动”按钮仍按原版操作。
4. 选中指挥官内已收纳的单个单位，若存在合法部署位置，自动进入该单位的退出模式。选中指挥官本人不会自动展开整支军队。
5. 主动点击“增援”时，仅当总共拥有一位指挥官且可增援时直接派遣；拥有多位时，即使只有一位合法，也仍需选择。
6. 没有实际收纳单位的己方指挥官，脚下显示淡粉色格子底座。正在路上的增援不算已收纳。底座提示“空军队”，不代替原版移动力与晋升面板。

设置
从主菜单“选项”，或游戏内暂停菜单“选项”，进入“附加内容”标签并下滚到“微操大师常凯申”分组。十二行功能配有并排的“鼠标／键盘”和“手柄”两列，使用与原版一致的 checkbox。鼠标十二项、手柄十一项，23 项默认全部勾选；“右键加入指挥官”的手柄格直接显示“不适用”。
点击原生“确认变更”保存并生效；“取消变更”或 Esc／B 使用原版取消流程，放弃未保存的修改。“恢复微操大师常凯申默认”仅启用本 Mod 的适用设置，仍需确认变更；底部原版“重设”仍是整个游戏选项的重设操作。
设置在读档、重启后保留，自动沿用 0.3.0 / 0.4.0 已保存的两组配置。旧的独立战争操作标签页及右上角战争按钮已移除。
游戏原生输入设备状态决定当前使用哪组配置；切换输入设备时粉色底座立即更新，自动选格功能从下次选中单位开始按新配置判断。关闭某项恢复该项原版操作，全部关闭仍保留设置入口；单人集中火力仍采用原地齐射及临时加成。第 3 项只处理右键指令，不把手柄 B 改成加入。

取消
使用原版右键 / Escape / 手柄 B 取消选格。取消后保持默认操作，不会因界面刷新立即再次进入；切换单位再重新选中，才会重新判断。
实机鼠标与键盘验证、手柄验证范围见 VALIDATION-zh-CN.txt。

安装
关闭游戏，把压缩包内 civ7-war-controls 文件夹放入：
%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VII\Mods\
应得到 Mods\civ7-war-controls\war-controls.modinfo。
在游戏“附加内容”确认启用，再加载存档。本 Mod 设置 AffectsSavedGames=0，允许在已有存档使用。

停用与回退
在附加内容停用本 Mod，重载游戏即可恢复原版操作。0.1.0 保留为仅含“选中腹内单位自动退出”的最小实验版；替换版本前关闭游戏，不要同时安装两个同 ID 副本。

开发
ui/war-controls.js 对接原生 API 并跟踪本 Mod 的自动选格；selection-assist.js 管理每次选中的一次自动切换；command-hooks.js 包装右键、增援入口和单位面板的自动焦点恢复。
focus-bonus.js 配合 data/ 中的数据库效果管理每发攻击的临时加成开关；focus-cost.js 结算指挥官移动力，并恢复加载时尚未结清的实际开火费用。
tactical-controls.js 管理连续选择、原地齐射、参与者预览和增援切换，并在卸载、取消或设置变化时清理待执行动作。
settings-store.js 负责两组设置与共享存储隔离；native-options.js 管理原生选项的草稿、确认与取消；settings-layout.js 仅为本 Mod 的选项生成两列布局；settings-ui.js 将配置加入共用的 mods 分类，text/settings.xml 提供中英文本。旧版 gamepad.rightClickJoin 字段仅为存储兼容保留，不生成控件且不用于手柄行为。源码包内运行 npm test 可执行自动检查。
