# 更好的手柄支持 · Better Controller Support

当前版本 **0.10.1**，2026-11-06。本版只整理中英文说明与功能边界，不改变运行行为，也不声称新的修复或实机验证。0.10.0 已发布的运行基线继续承接；本次没有新的实体手柄、Windows 或游戏内实测。

## 当前 6 类功能

| 功能 | 入口 | 行为 |
| --- | --- | --- |
| 摇杆兼容修复 | 选项 → 附加内容 → 本 Mod 设置 | 默认关闭。只在设备需要时手动启用；可分别设置摇杆交换和上下翻转，已有设置会保留。 |
| 地图工具轮盘 | 打开原生轮盘，LB／RB 切至地图工具 | 提供滤镜、城市、单位、奇观和地图钉入口，沿用左下角工具按钮的图标。选中后按 A 一次直接打开对应界面，按 B 返回。Map Trix 与 Detailed Map Tacks 均为可选；缺失时隐藏对应入口。 |
| 地图选中地块居中 | 开启输入兼容后，地图上按 R3 | 把当前选中格移动到镜头中央，便于查看和继续操作。 |
| 菜单滚动导航 | 菜单中按 R3；右摇杆左右／上下 | R3 聚焦当前滚动区可见中心附近的可选项；明确的右摇杆左右拨动切换滚动区；上下持续滚动会加速，提示跟随当前区域。 |
| 同格单位与定居点 | LB／RB 循环；X 打开定居点 | 同一格有多个己方单位时，LB／RB 依序循环。选择单位前后都可用 X 打开该格定居点；能否打开和执行沿用原版合法性判断。 |
| 强制结束回合 | 长按 View／Back 约 1 秒后松开 | 短按仍打开社交面板。长按满 1 秒后松开调用原生强制结束回合；仍遵守原生必要阻塞、存档流程和 Rest Guard，不绕过守卫。 |

## 升级与设置

更新时请替换本 Mod 的完整目录，避免旧文件残留。保留内部 Mod ID 和已有设置，不需要重置设置。不要与旧的独立 Mac 手柄修复同时启用，也不要同时保留重复的本地版和工坊版副本。

本版运行文件与已发布 0.10.0 基线一致。136 项离线回归通过（无跳过）；本次未增加游戏内、实体手柄或 Windows 实测。详细记录见 [验证记录](VALIDATION.md)。

开发：`npm test`；设置 `CIV7_PLAYWRIGHT_MODULE` 可运行独立浏览器回归，不连接游戏。`python3 tools/package.py` 只生成运行包。
