# 更好的手柄支持 · Better Controller Support

当前发行版本 **0.10.2**：整合三项设置存储修复（多键兼容、旧版校准迁移、失败保存恢复）、菜单／滚动改进和自动本地诊断。详见 [存储修复](docs/storage-review-fixes.md)、[集成记录](docs/integration-20261113.md) 与 [滚动修复](docs/scroll-followup-20261114.md)。

加载游戏页只保留随当前滚动区移动的 RS 标记，定向隐藏该页右侧原生重复图标，离开后恢复。满幅持续推动右摇杆，约 1.8 秒达到最高速度后，完整滚动距离可在 3 秒内走完；轻推仍按幅度减速，松杆、反向、弹窗接管会重置加速。其他页面的原生图标不采用这项页面专用隐藏规则。

## 升级与设置

更新时请替换本 Mod 的完整目录，避免旧文件残留。保留内部 Mod ID。支持按存储键精确读取的正常后端可加载旧版校准，并在确认保存时迁移；存在 macOS 存储键读取故障的旧记录需要按 [迁移说明](docs/storage-review-fixes.md) 处理，不能通过重置或清空其他 Mod 设置解决。不要与旧的独立 Mac 手柄修复同时启用，也不要同时保留重复的本地版和工坊版副本。

## 自动控制器诊断

> 自动诊断已通过离线验证并安装到本机开发版；Gameface 持久化和本次新增代码的实体手柄表现仍需单独验证。

诊断默认常开，与“显示调试面板”和兼容修复开关无关。它只记录本页启动版本、已验证的五项已持久化配置、地图／菜单实际生效配置、设备／输入上下文／视图／面板／阻塞原因、引擎命名动作及轴向量，以及地图／菜单桥的映射、透传、抑制和错误结果；`nav-move` 只标为引擎 ACTION 流，不能判断物理左／右摇杆，也不能定位硬件或驱动根因。诊断会解析最新共享文档以安全合并自己的命名空间，但绝不把其他设置写入诊断记录。不会记录界面文字、存档、玩家名或聊天，不发送游戏命令，也不上传数据。

最多保留最近 3 个 shell/game 页面会话的启动信息、初始和最新状态摘要（不随输入事件滚动丢弃），所有会话合计最多 512 条输入／变化事件和 96 KiB UTF-8 JSON。每个输入来源／处理阶段最多接纳每秒 4 条；人工标记及其他状态记录也有限流和容量限制，额外样本只进入有界计数；脏数据通常不超过每 10 秒同步写一次。写入时只替换本页会话，并从最新存储保留其他页面会话。数据只合并到已有且精确验证通过的共享 `modSettings` 中的 `civ7-map-tools-gamepad.diagnostics.v1` 命名空间，不创建第二个 LocalStorage 键，也不由诊断创建空共享设置。首次安装尚无已验证的 BCS 校准配置时，只在当前页面内存中记录；关闭页面后无法恢复这部分记录。存储无效、模糊、配额不足或读回失败时会停止本页后续持久化并保留内存快照。页面卸载会尽力同步写入；进程崩溃、断电或无法验证的存储仍可能丢失最后一批数据。

页面仍存活时，在开发控制台调用 `globalThis.__civ7BetterControllerDiagnosticsV1.snapshot()` 取得只读副本；`flush()` 可请求一次尽力写入，`mark('短标签')` 可加入人工标记，三者都不会发出输入或游戏命令。离线提取时先退出游戏并复制 `LocalStorage.sqlite`，再对副本读取准确行：`sqlite3 backup-LocalStorage.sqlite "SELECT value FROM \"Values\" WHERE id='fs://game' AND key='modSettings';"`，解析 JSON 中上述诊断命名空间。只读副本；不要清空、改写或直接操作实时数据库。
