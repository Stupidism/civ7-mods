# 更好的手柄支持 · Better Controller Support

源码目录：`civ7-better-controller-support`。Mod ID 和手动安装目录继续使用 `civ7-map-tools-gamepad`，保持已安装版本及设置兼容。

版本 0.3.0（88 项离线检查通过，新增同格操作尚未实机验证）。独立的《文明 VII》界面模组，为 Windows 和 macOS 增加地图工具手柄入口、同格单位切换和定居点快捷打开，内置 Mac Controller Support Fix 0.1.5 的地图输入和菜单摇杆兼容功能。

## 同格单位和定居点

在普通地图或单位已选中时，以当前高亮的光标格为目标（Xbox 布局）：

- 该格有两个或更多己方单位时，**RB 下一个、LB 上一个**，循环选择同格单位。探索者、移民、商人、休眠或已耗尽行动力的单位都包含在内；不跳到其他地块，不包含敌方或已收纳离开地图的单位。未选单位时也能直接切入。
- 该格有定居点时，**X 直接打开定居点**，不需要先选中或取消单位。自己的城市、城镇走原版管理界面；其他文明和独立势力沿用原版外交与接触限制。普通乡村地块不算定居点所在格。
- 没有重叠单位／定居点时保留对应按键原功能。轮盘内的 LB/RB 仍切换分类；移动选格、攻击、城市界面、弹窗和焦点锁内不接管。重叠格上的 RB 用于单位切换，打开轮盘需先取消单位并把光标移到无重叠单位的格子。

这两项快捷操作在 Windows/macOS 均启用，不依赖 Map Trix，也不依赖 Mac 输入兼容开关。仅离线验证，尚未实体手柄或 Windows 实机验收。

## 怎么用

1. 在普通地图打开游戏轮盘（Xbox 布局为 RB；其他设备按游戏提示）。
2. 用 LB / RB 切换到 **地图工具** 分类，左摇杆选工具，按一次 **A** 直接打开对应界面。
3. 列表中用方向键或左摇杆选择，**A** 执行原按钮功能；**B** 关闭工具并直接回到地图。无需经过左下角按钮区。

轮盘五个图标与左下角工具按钮使用相同图片。选中项有金色边框。长列表会滚动到选中行，隐藏和禁用项会跳过。奇观的 A 操作沿用 Map Trix：有已知位置时定位到地图，未有位置时只供查看。

滤镜面板继续使用游戏原生导航和开关。地图钉选择器中，上下按图标位置导航，左右可以顺序遍历全部图标；A 选择后进入原模组的地图放置流程，B 关闭选择器。地图放置、预览与删除功能仍由 Detailed Map Tacks 提供，本模组不新增删除快捷键；完整放置链路和各手柄型号仍待实机验收。

## 地图控制与设置

Mac 默认启用输入兼容，Windows 和未识别平台默认沿用原生地图输入；地图工具在两者上都启用。旧模组保存过的兼容开关、左右摇杆方向、调试栏设置原样继承，优先于平台默认值。

兼容开启时（Xbox 布局）：

| 按键 | 功能 |
| --- | --- |
| 左摇杆 | 移动选中地块，镜头跟随 |
| 右摇杆 | 平移镜头 |
| 右摇杆按下（R3） | 把选中地块移到镜头正中 |
| 方向键 | 普通地图移动光标；选中单位时保留原生按钮导航 |
| LB / RB | 有重叠单位时切换同格单位；其他情形保留原操作，普通地图 RB 打开轮盘 |
| LT / RT | 每次按下缩小／放大一级 |
| A / B | 原生确认／取消 |
| X | 优先打开光标格上的定居点；无定居点时普通地图打开轮盘，选中单位时进入移动 |
| Y | 原生下一行动，可能结束回合 |

菜单摇杆的持续输入会转换为原生菜单接受的状态。保持原生输入路由、焦点、教程和对话框限制；切换菜单、失焦或控制器断开时清理运动输入。菜单修复仍需用户实机确认。

在“选项 → 附加内容 → 更好的手柄支持”可独立调整兼容开关、左右摇杆上下方向和调试栏，确认后保存，取消不应用。调试栏默认隐藏。关闭兼容开关只关闭地图输入桥接和菜单摇杆修复，地图工具入口继续可用；左右方向选项只在兼容开启时生效。

### 从旧 Mac 模组迁移

只需启用本模组，停用“Mac 手柄支持修复”后重启游戏，旧设置会自动读取，无需重新配置。两者同时启用时本模组提供地图工具及同格快捷操作，旧模组负责输入兼容和设置；快捷入口在旧模组（加载顺序 4000）及本模组兼容层之后加载。停用旧模组并重启后才由合并版接管输入兼容。不会自动取消旧模组订阅或改写它的文件。

## 可选兼容模组

| 工具 | 来源 |
| --- | --- |
| 滤镜 | 原版游戏 |
| 城市、单位、奇观 | Map Trix（`bz-map-trix`） |

只显示当前实际存在且可用的入口，不需要同时安装所有可选模组。不附带、不改写第三方模组文件。普通地图的轮盘仍遵守原版教程和视图限制。

## 安装

把 `civ7-map-tools-gamepad` 文件夹放入游戏的 `Mods` 目录，确保 `map-tools-gamepad.modinfo` 位于该文件夹第一层。重启游戏，在“附加内容”启用“更好的手柄支持”。

- Windows：`%LOCALAPPDATA%/Firaxis Games/Sid Meier's Civilization VII/Mods/`
- macOS：`~/Library/Application Support/Civilization VII/Mods/`

不要同时安装同一 Mod ID 的多个副本。关闭模组并重启即可恢复原有界面。

## 验证与边界

0.3.0 新增同格操作离线回归，覆盖原版输入分发、原版定居点选择、Mac 兼容链、目标变化及取消。历史 0.2.1 的 76 项检查涵盖地图工具一次确认打开等行为。0.2.0 取图期间收到用户对 Mac 地图输入、R3 和轮盘摇杆的实机反馈；这些反馈不代表新快捷操作已经实机验收。Windows、设置保存及完整地图钉链路仍未验收。详细范围见 [VALIDATION.md](VALIDATION.md)。

它只在本地保存手柄设置，不改变游戏规则，声明 `AffectsSavedGames=0`。通过 A 操作城市、单位或地图钉仍会执行原工具的正常行为。暂停、对话框、焦点锁和休息遮罩优先；控制器之外的输入沿用游戏处理。其他改写 ContextManager 输入链或相同面板的模组可能需要进一步适配。

开发回归：`npm test`。完整浏览器回归需设置 `CIV7_PLAYWRIGHT_MODULE`，可选 `CIV7_CHROMIUM_PATH` 和 `CIV7_MODULES_DIR`；测试启动独立浏览器，不连接游戏。不带这些环境变量时会明确跳过浏览器用例。

实机测试前必须按仓库 `AGENTS.md` 取得游戏锁、完整备份并核验整个 Saves 目录、暂停 Rest Guard 的全部限制；结束后恢复。文件安装不需要加载或修改存档。
