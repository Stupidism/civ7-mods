当前源码候选版本 **0.10.2-dev**（2026-11-13 集成），工坊已发布版本仍为 **0.10.1**。候选同时保留三项设置存储修复（多键兼容、旧版校准迁移、失败保存恢复），并合入已由用户确认的菜单／滚动运行改进：滚动提示改用游戏原生 NavigationTray，`civ7-controller-scroll` 可被弹出层取消并获得帧所有权。以上仍仅做离线验证，本候选尚未安装或实机验收。详见 [存储审查修复](docs/storage-review-fixes.md) 与 [集成记录](docs/integration-20261113.md)。

## 当前 6 类功能

| 功能 | 入口 | 行为 |
| --- | --- | --- |
| 摇杆兼容修复 | 选项 → 附加内容 → 本 Mod 设置 | 默认关闭。只在设备需要时手动启用；可分别设置摇杆交换和上下翻转，已有设置会保留。 |
| 地图工具轮盘 | 打开原生轮盘，LB／RB 切至地图工具 | 提供滤镜、城市、单位、奇观和地图钉入口，沿用左下角工具按钮的图标。选中后按 A 一次直接打开对应界面，按 B 返回。Map Trix 与 Detailed Map Tacks 均为可选；缺失时隐藏对应入口。 |
| 地图选中地块居中 | 开启输入兼容后，地图上按 R3 | 把当前选中格移动到镜头中央，便于查看和继续操作。 |
| 菜单滚动导航 | 菜单中按 R3；右摇杆左右／上下 | R3 聚焦当前滚动区可见中心附近的可选项；明确的右摇杆左右拨动切换滚动区；上下持续滚动会加速；提示进入原生 NavigationTray。弹出层可取消同一路由输入或声明当前帧，此时后台滚动立即停止。 |
| 同格单位与定居点 | LB／RB 循环；X 打开定居点 | 同一格有多个己方单位时，LB／RB 依序循环。选择单位前后都可用 X 打开该格定居点；能否打开和执行沿用原版合法性判断。 |
| 强制结束回合 | 长按 View／Back 约 1 秒后松开 | 短按仍打开社交面板。长按满 1 秒后松开调用原生强制结束回合；仍遵守原生必要阻塞、存档流程和 Rest Guard，不绕过守卫。 |

## 升级与设置

更新时请替换本 Mod 的完整目录，避免旧文件残留。保留内部 Mod ID。支持按存储键精确读取的正常后端可加载旧版校准，并在确认保存时迁移；存在 macOS 存储键读取故障的旧记录需要按 [迁移说明](docs/storage-review-fixes.md) 处理，不能通过重置或清空其他 Mod 设置解决。不要与旧的独立 Mac 手柄修复同时启用，也不要同时保留重复的本地版和工坊版副本。

已发布 0.10.1 的运行文件与 0.10.0 基线一致，其历史 136 项离线回归通过（无跳过）。0.10.2-dev 同时修改存储运行代码和菜单／滚动运行文件，不能直接沿用已发布版验收；2026-11-09 的 159 项存储修复结果只代表当时候选，不覆盖本次运行文件组合。当前边界和本轮离线结果见 [集成记录](docs/integration-20261113.md)，尚未增加游戏内、实体手柄或 Windows 实测。详细历史见 [验证记录](VALIDATION.md)。

开发：`npm test`；设置 `CIV7_PLAYWRIGHT_MODULE` 可运行独立浏览器回归，不连接游戏。`python3 tools/package.py` 只生成运行包。
