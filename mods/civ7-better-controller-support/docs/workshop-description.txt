[h1]更好的手柄支持 · Better Controller Support[/h1]
用手柄访问地图工具、切换同格重叠单位、打开被单位挡住的定居点。内置 Mac 地图输入与菜单摇杆兼容。

[h2]同格单位与定居点（0.3.0）[/h2]
[list]
[*][b]LB / RB 切换同格单位[/b]：光标格内有两个或更多己方单位时，LB 上一个、RB 下一个，循环选择，不跳到其他地块。包含探索者、移民、商人、休眠和已耗尽行动力的单位；不包含敌方或已收纳离开地图的单位。未选中单位时也能直接切入。
[*][b]X 直接打开定居点[/b]：光标格上有城市或城镇时，无论是否已选中单位，按 X 打开对应界面。自己的定居点打开管理界面，其他文明和独立势力沿用原版外交与接触限制。普通乡村地块不算定居点所在格。
[*]没有对应目标时，按键保留原功能。菜单内 LB/RB 仍切换分类；移动、攻击选格和弹窗优先。重叠格上的 RB 用于切换单位；需要开轮盘时，可取消单位并把光标移到无重叠单位的格子。
[/list]
这些同格快捷操作不需要 Map Trix，也不依赖 Mac 输入兼容开关。按键说明使用 Xbox 布局，其他手柄按游戏显示的对应按键操作。

[h2]地图工具[/h2]
普通地图 RB 打开原生轮盘，LB/RB 切换到“地图工具”，左摇杆选择工具，按一次 A 直接打开对应界面。方向键或左摇杆导航，A 确认，B 关闭工具并直接回地图，无需经过左下角按钮区。

轮盘图标与左下角工具按钮相同。金色边框标出焦点，长列表自动滚动，跳过隐藏或禁用项。滤镜面板保留原生控件；地图钉选择后交还原模组放置流程。本模组没有新增地图钉删除快捷键。

[h2]兼容与可选模组[/h2]
[list]
[*]原版滤镜、同格单位切换和定居点快捷打开：无需其他模组。
[*]城市、单位、奇观[b]列表[/b]：[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3507072814]Map Trix[/url]。
[*]地图钉：[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3507297712]Detailed Map Tacks[/url]。
[/list]
缺少可选模组时，对应地图工具入口隐藏。不附带或改写第三方模组，不提供系统手柄驱动。适用于 Windows/macOS；其他改写相同输入链的模组可能需要适配。

[h2]Mac 地图输入与设置[/h2]
Mac Controller Support Fix 0.1.5 的功能已内置。Mac 默认开启输入兼容，Windows 默认沿用原生地图输入；地图工具与同格快捷操作不受此开关影响，旧设置优先于默认值。

兼容开启时：左摇杆选地块，右摇杆移镜头，R3 把选中地块移到镜头正中；LT/RT 每次缩放一级。A/B 沿用原生确认取消。X 优先打开当前格定居点；无定居点时，普通地图打开轮盘，单位已选中时进入移动。Y 是原生下一行动，可能结束回合。菜单摇杆持续输入兼容，左右摇杆上下方向可独立设置，调试栏默认隐藏。

设置入口：选项 → 附加内容 → 更好的手柄支持。确认保存，取消放弃。暂停菜单、对话框、焦点锁和休息限制优先。
[b]已装旧 Mac 模组：建议停用旧模组后重启。[/b]同时启用时，旧模组负责输入兼容和设置，本模组提供地图工具及同格快捷操作；不会自动取消旧订阅。

[h2]安装与验证[/h2]
订阅后等待 Steam 下载，重启游戏，在“附加内容”启用。手动版和工坊版只保留一份，内部 ID 为 civ7-map-tools-gamepad。模组不新增游戏规则，使用原工具仍会执行正常游戏操作。

[h1]English[/h1]
Controller access to map tools, stacked units and settlements, with integrated Mac input compatibility.

[h2]Stacked units and settlements (0.3.0)[/h2]
[list]
[*][b]LB/RB cycle units on the highlighted plot[/b] when two or more of your units share it. LB selects the previous, RB the next, wrapping within that plot. Includes explorers, settlers, merchants, sleeping and exhausted units. Excludes foreign and packed/off-map units. Works before selecting a unit too.
[*][b]X opens the settlement on that plot[/b], before or after selecting a unit. Your cities/towns open management; foreign and independent settlements retain native diplomacy/contact rules. Remote rural tiles do not count as settlement tiles.
[*]Without a matching target, original button functions remain. Menu tabs, move/attack targeting and dialogs retain control. RB cycles units over a stack; to open the radial menu, deselect and move the cursor to a plot without stacked units.
[/list]
Xbox layout shown. These plot shortcuts work independently of the Mac compatibility switch and need no other mod.

[h2]Map Tools[/h2]
Open the native radial menu with RB, switch to Map Tools with LB/RB, select with the left stick and press A once to open the tool. D-pad/left stick navigate; A activates and B closes directly to the map. Icons match the minimap buttons. Gold focus outlines, scrolling lists and hidden/disabled-item skipping keep navigation clear.

Base lenses retain native controls. City, unit and wonder [b]lists[/b] require [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3507072814]Map Trix[/url]. Map tacks require [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3507297712]Detailed Map Tacks[/url]. Missing tools are hidden. Placement/removal remains the original mod's responsibility; no new tack-deletion shortcut. Third-party files are not bundled or modified.

[h2]Mac compatibility and settings[/h2]
Includes Mac Controller Support Fix 0.1.5. Compatibility defaults on for Mac and off for Windows; saved preferences take priority. Left stick moves the plot cursor, right stick pans, R3 centers the selected plot on the camera, LT/RT zoom one step. X prioritizes a settlement; otherwise it opens the radial menu or unit movement. Y invokes native next action and may end the turn. Held menu analog input is normalized for native menus.

Options → Add-ons → Better Controller Support offers compatibility, separate vertical inversion for each stick and an optional debug bar. Confirm saves; Cancel discards. Pause screens, dialogs, focus locks and rest restrictions take priority. Disable the old Mac fix and restart to use the integrated implementation. If both are enabled, the old fix handles compatibility/settings and this mod adds map tools and plot shortcuts. No automatic unsubscription or external controller driver.

[h2]Install and verification[/h2]
Subscribe, wait for Steam to download, restart and enable in Additional Content. Keep one copy of civ7-map-tools-gamepad.
[b]0.3.0 passes 88 offline checks. New plot shortcuts have not been live-tested.[/b] Earlier 0.2.0 Mac input/R3/radial feedback does not validate this release. Settings persistence needs further investigation; Windows, broad controller coverage, multiplayer and complete map-tack placement/removal remain unverified. Other mods changing the same input pipeline may need adaptation.
