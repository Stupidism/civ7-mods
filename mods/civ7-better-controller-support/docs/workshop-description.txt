[h1]更好的手柄支持 · Better Controller Support[/h1]
用手柄访问《文明 VII》左下角的地图工具。0.2.1 已合并 Mac 手柄支持修复，安装一个模组即可使用两套功能。

[h2]主要功能[/h2]
[list]
[*]原生轮盘新增“地图工具”分类，图标与左下角工具按钮一致。
[*]方向键或左摇杆切换按钮和列表，A 确认，B 返回。
[*]金色焦点高亮，长列表自动滚动，跳过隐藏和禁用项。
[*]地图钉选择器支持图标导航，选中后交还原模组的地图放置流程。
[*]内置 Mac 地图输入修复：左摇杆选地块，右摇杆移镜头，RB 开轮盘，R3 把选中地块移到镜头正中。
[*]左右摇杆上下方向独立设置，菜单摇杆持续输入兼容，调试栏默认隐藏。
[*]暂停菜单、对话框、焦点锁和休息限制优先。
[/list]

[h2]操作方式（Xbox 布局）[/h2]
1. 普通地图按 RB 打开轮盘。
2. LB / RB 切换到“地图工具”，左摇杆选中工具，按一次 A 直接打开对应界面。
3. 方向键或左摇杆导航，A 确认；B 关闭工具并直接返回地图。
其他手柄按游戏显示的对应按键操作。滤镜面板保留原生控件；轮盘仍遵守游戏的教程和当前视图限制。

可选模组未启用时，对应入口隐藏。不附带 Map Trix、Detailed Map Tacks 或游戏图片，也不提供系统手柄驱动。适用于 Windows / macOS 的游戏界面；其他修改相同输入链的模组可能需要适配。

[h2]地图兼容与旧版迁移[/h2]
Mac 默认开启输入兼容；Windows 默认使用原生地图输入。地图工具不受此开关影响。旧版保存过的四项设置直接继承，优先于默认值。
“选项 → 附加内容 → 更好的手柄支持”可调整兼容开关、左右方向和调试栏，确认保存、取消放弃。方向设置仅在兼容开启时生效。
兼容开启时，LT/RT 每次缩放一级；普通地图方向键移光标，选中单位后保留按钮导航。A/B 原生确认取消，X 轮盘或单位移动，Y 原生下一行动（可能结束回合）。
[b]已装旧 Mac 模组：停用旧模组后重启。[/b]同时启用时会由旧模组负责输入和设置，合并版只提供地图工具，避免重复处理；停用旧版重启后才由合并版接管。不会自动取消旧订阅。

[h1]English[/h1]
Bring the minimap tools within reach of your controller. Better Controller Support adds a [b]Map Tools[/b] category to Civilization VII's native radial menu, using the same icons as the original minimap buttons.

[h2]Controls[/h2]
Open the radial menu with RB, switch to Map Tools with LB/RB, select a tool with the left stick and press A once to open it directly. Navigate with the D-pad or left stick, press A to activate, and B to close the tool and return directly to the map.

Gold outlines identify focus. Long lists scroll to the selected row and skip hidden or disabled entries. The lens panel retains its native controls. Map-tack icons support directional navigation; placement returns to the original mod. Dialogs, pause screens and focus locks take priority.

[h2]Optional integrations[/h2]
Base-game lenses work on their own. Cities, units and wonders require [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3507072814]Map Trix[/url]. Map tacks require [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3507297712]Detailed Map Tacks[/url]. Missing tools are hidden. Neither mod is bundled or modified.

[h2]Integrated map and menu compatibility[/h2]
Mac Controller Support Fix 0.1.5 is now included. Compatibility defaults on for Mac and off for Windows; Map Tools works independently. Existing saved preferences are retained.
Left stick moves the plot cursor, right stick pans, R3 centers the selected plot on the camera, RB opens the radial menu on the normal map, LT/RT zoom one step per press. Unit/menu navigation stays native. A/B stay native; X invokes radial/unit movement; Y is native next action and can end the turn. Held menu analog input is normalized for native menus.
Options → Add-ons → Better Controller Support has compatibility, independent left/right vertical inversion and an optional debug bar. Confirm saves; Cancel discards. Debug defaults off.
Disable the old Mac Controller Support Fix and restart to use the integrated implementation. If both remain enabled, the old mod handles input/settings and this mod supplies Map Tools, preventing duplicate handlers. No automatic unsubscription. No external controller drivers included.
