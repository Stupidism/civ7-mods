[h1]更好的手柄支持 · Better Controller Support[/h1]
让手柄更方便地操作地图工具、重叠单位、长列表和回合收尾。
[list]
[*]摇杆兼容修复默认关闭，可在选项 → 附加内容中按设备需要手动启用；摇杆交换与上下翻转分别设置，保留已有设置。
[*]地图工具轮盘沿用原图标，提供滤镜、城市、单位、奇观和地图钉。选中后按 A 一次直接打开，按 B 返回。Map Trix 与 Detailed Map Tacks 为可选，缺失时隐藏对应入口。
[*]开启输入兼容后，地图上按 R3，把当前选中格移到镜头中央。
[*]菜单中按 R3，聚焦当前滚动区可见中心附近的可选项；右摇杆明确左右拨动切换滚动区，上下持续滚动逐渐加速，提示跟随当前区域。
[*]同一格有多个己方单位时，LB／RB 循环切换；选择单位前后都可用 X 打开该格定居点，合法性沿用原版判断。
[*]View／Back 长按满 1 秒后松开，调用原生强制结束回合；短按保留社交面板。仍遵守原生必要阻塞、存档流程和休息守卫。
[/list]

[h2]English[/h2]
Controller navigation for map tools, stacked units, long lists, and turn wrap-up.
[list]
[*]Stick compatibility correction defaults OFF in Options → Add-Ons; enable it manually and configure stick swap and vertical inversion separately. Existing settings are preserved.
[*]The familiar map-tools radial provides filters, cities, units, wonders, and tacks. Press A once to open directly and B to return. Optional Map Trix and Detailed Map Tacks entries are hidden when absent.
[*]With input compatibility enabled, press R3 on the map to move the selected plot to the camera center.
[*]In menus, R3 focuses a selectable item near the visible center of the active scroll region. Deliberate right-stick horizontal movement switches regions; sustained vertical scrolling accelerates with active-region hints.
[*]LB/RB cycles several of your units on one plot. Before or after selecting a unit, X opens that plot's settlement; native legality checks remain in force.
[*]Hold View/Back for one second, then release to invoke native force-end-turn. Short press keeps the social panel. Native blockers, save flows, and rest guards remain respected.
[/list]
Optional page mods: [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3822254182]Resource Planner[/url] provides resource layout, allocation preferences, empty-slot reminders, deferral, and skip-this-turn. Better Settlement UI provides four-column layouts, scores, payback, sorting, build deferral, and skip-this-turn. [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3831747669]Better Policy UI[/url] provides compact layouts plus policy/tradition/crisis empty-slot reminders, deferral, and skip-this-turn.
Replace the complete old folder, keep the internal ID and settings, and avoid duplicate local/Workshop copies or the old Mac fix.
