# 加载游戏页 RS 提示与滚动速度修复

2026-11-14，0.10.2-dev 后续候选；基线提交为 `2cfa5e5`。

## 行为

- 只对当前加载游戏页右侧详情滚动条的原生 `inline-scroll-pan` 提示添加可撤销隐藏类。自定义 RS 标记继续跟随当前滚动区域；不修改原生输入开关，不移动或删除原生提示节点。其他页面和页脚提示不采用这项隐藏规则。
- 兼容右侧不溢出、原生提示节点重建和原生更新重写 `display`。切页、暂停、弹窗接管和销毁时撤销本 Mod 的隐藏类。文档级作用域还要求焦点属于加载游戏页，避免处理被其他界面覆盖的页面。
- 保留起步速度、600 毫秒延迟和 1200 毫秒渐进加速。最高速度按完整可滚动距离计算，满幅推杆到达最高速度后，完整范围在 3 秒内可滚完；保留正常帧的实际耗时，并为最后一帧留出时间余量。轻推按幅度减速。
- 超过输入有效期、松杆、方向反转、换页和弹窗接管仍停止或重置滚动，不积累暂停后的位移。

## 三项存储修复的含义与测试

| 修复 | 保护的行为 | 验证方式 |
| --- | --- | --- |
| 多键兼容 | “键”是数据库记录键，不是手柄按键。正常按键读取的后端允许其他 Mod 的设置与本 Mod 共存。 | 隔离夹具放入本 Mod 与其他 Mod 的记录，保存手柄设置，再重建实例；检查双方数据完整。实际游戏可检查确认设置、重启后的保留，以及其他 Mod 设置未变。 |
| 旧校准配置迁移 | 旧 0.3.0 的摇杆交换与翻转设置可被读取，成功确认保存后才迁入新命名空间。 | 用旧配置夹具验证取消不迁移、确认后值不变、新配置优先。无法准确识别键的 macOS 后端不猜测归属，只允许在数据库备份副本上审查迁移。 |
| 保存失败回滚 | 写入后读回失败时，尝试恢复旧设置，避免已报失败的新设置在下一次启动偷偷生效。 | 模拟写入抛错、读回错误、同时出现其他 Mod 数据，再重建实例验证。故障注入仅在夹具中进行；持续存储故障可能连恢复也失败，此时明确报告错误，不声称恢复成功。 |

普通用户无需人为破坏真实设置数据库。完整存储边界见 [存储审查修复](storage-review-fixes.md)。
