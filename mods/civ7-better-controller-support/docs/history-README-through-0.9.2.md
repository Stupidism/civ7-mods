## 滚动区域与焦点（2026-10-31，源码已实现，尚未安装）

在有滚动内容的菜单中，按下右摇杆立即把焦点移到当前滚动区域可见中央附近的可用控件，只移动焦点，不确认操作。右摇杆上下滚动；明确向左／右推可在多个滚动区域之间切换，当前滚动条以金色轮廓标记。横向幅度至少 0.75 且为纵向的两倍；一次推杆只切换一次，上下滚动不能直接斜转为切区，须先回中。到最左／右不循环跳转。

底部原生手柄指引旁增加设备按键图标及“按下：焦点移至可见区域中央”“← → 切换滚动区域”。单滚动区隐藏切区提示；没有可选控件的详情区只滚动，按下不改变原焦点。切区本身不移动选中项。支持原版 FxsScrollable 与 Solid ScrollArea；其他自定义滚动控件尚未覆盖。地图上的 R3 入口保持原行为。

## 手动交换左右摇杆

“选项 → 附加内容 → 更好的手柄支持”提供“交换左右摇杆”。用户报告需要兼容开启、交换开启、两项上下翻转关闭。本地已安装补丁将这个开关接入启动主菜单、局内暂停菜单及仍属于该视图的选项／存档等子页面：交换焦点导航与滚动，目标是校正后的左摇杆移动焦点、右摇杆滚动。菜单不采用地图的上下翻转。

商人列表、轮盘和其他局内面板保持此前的摇杆职责；用户已报告商人能用左摇杆选城市，因此未将此次交换扩大到这些面板。十字键与确认／取消不变。切换设置会停止补丁发起的滚动，确认后应用；关闭兼容恢复原生处理。交换默认关闭，旧配置及翻转偏好保留。

该开关也覆盖小型事件选项弹窗。兼容开启时，这种弹窗临时使用纯菜单输入，左摇杆和十字键沿原版面板导航切换选项；拦截旧混合输入模式残留的镜头缩放／地图移动。只移动焦点，不自动确认奖励。弹窗关闭或兼容停用后恢复原生上下文，弹窗之上的新面板、焦点锁和休息遮罩优先。

## 资源和政策别忘记

- **资源**：同时有未分配资源和至少一个实际可分配的空槽，才加入回合末待办。用原版合法性检查确认目标，排除已锁定的分配、帝国／宝藏类资源和无法接纳该卡的槽位。
- **政策**：普通政策、传统、危机政策任一槽位空着，就加入回合末待办。即使暂时没有可用卡，也可以明确跳过。
- 这些事项排在普通行动、剩余单位行动之后，显式延后的“最后建造”之前。点击右下角或按下一行动会进入资源／政策界面，只有危机槽空着时直接进入危机政策页。关闭界面后仍按实际已分配状态检查，不会因“看过了”而忘记。
- 在资源分配页或政策／传统／危机政策页，**长按 X 满 1 秒后松开**，或点击“本回合跳过”。资源与政策分别跳过，下一回合自动恢复检查；政策跳过涵盖三类政策槽。短按 X 保留原功能。
- 跳过会调用原版“已考虑分配”的合法入口，不会分配卡片，也不确认或丢弃政策草稿；界面保持打开，可自行确认或取消。游戏尚未认可的必要通知仍受原版限制。
- 未跳过的提醒会阻止普通结束回合及自动结束回合；明确的强制结束回合快捷键仍可使用。状态仅保存在本次对局界面内，重新加载会重新提醒。

## 同格单位和定居点

在普通地图或单位已选中时，以当前高亮的光标格为目标（Xbox 布局）：

- 该格有两个或更多己方单位时，**RB 下一个、LB 上一个**，循环选择同格单位。探索者、移民、商人、休眠或已耗尽行动力的单位都包含在内；不跳到其他地块，不包含敌方或已收纳离开地图的单位。未选单位时也能直接切入。
- 该格有定居点时，**X 直接打开定居点**，不需要先选中或取消单位。自己的城市、城镇走原版管理界面；其他文明和独立势力沿用原版外交与接触限制。普通乡村地块不算定居点所在格。
- 没有重叠单位／定居点时保留对应按键原功能。轮盘内的 LB/RB 仍切换分类；移动选格、攻击、城市界面、弹窗和焦点锁内不接管。重叠格上的 RB 用于单位切换，打开轮盘需先取消单位并把光标移到无重叠单位的格子。

这两项快捷操作在 Windows/macOS 均启用，不依赖 Map Trix，也不依赖 Mac 输入兼容开关。仅离线验证，尚未实体手柄或 Windows 实机验收。

## 怎么用

1. 在普通地图打开游戏轮盘（Xbox 布局为 RB；其他设备按游戏提示）。
2. 用 LB / RB 切换到 **地图工具** 分类，左摇杆选工具，按一次 **A** 直接打开对应界面。
3. 列表中用方向键或左摇杆选择，**A** 执行原按钮功能；**B** 关闭工具并直接回到地图。无需经过左下角按钮区。

轮盘五个图标与左下角工具按钮使用相同图片。选中项有金色边框。长列表会滚动到选中行，隐藏和禁用项会跳过。奇观的 A 操作沿用 Map Trix：有已知位置时定位到地图，未有位置时只供查看。

滤镜面板继续使用游戏原生导航和开关。地图钉选择器中，上下按图标位置导航，左右可以顺序遍历全部图标；A 选择后进入原模组的地图放置流程，B 关闭选择器。地图放置、预览与删除功能仍由 Detailed Map Tacks 提供，本模组不新增删除快捷键；完整放置链路和各手柄型号仍待实机验收。

## 安装

把 `civ7-map-tools-gamepad` 文件夹放入游戏的 `Mods` 目录，确保 `map-tools-gamepad.modinfo` 位于该文件夹第一层。重启游戏，在“附加内容”启用“更好的手柄支持”。

- Windows：`%LOCALAPPDATA%/Firaxis Games/Sid Meier's Civilization VII/Mods/`
- macOS：`~/Library/Application Support/Civilization VII/Mods/`

不要同时安装同一 Mod ID 的多个副本。关闭模组并重启即可恢复原有界面。
