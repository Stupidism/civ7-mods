# 单组配置文字导入：离线验证

日期：2026-10-22。版本：`0.3.4-dev` / modinfo `7`。

用户将桌面应用留为后续备选，要求先处理如下文字，并明确正在玩游戏、不要开启游戏调试：

```text
1游戏种子：1467319409 宽广盘古大陆 巨大
1地图种子：1467319429。
```

## 本轮修改

- 新建第一页第二个按钮改为“粘贴配置文字”。
- 用原版 `fxs-textbox` 接收文字。静态核对本机原版源码支持 `enabled`、`max-length`、`component-value-changed`；不依赖剪贴板读取权限。
- 有 `ClipboardEvent` 文字时直接解析并预览；没有事件内容时保留原生粘贴，读取输入框变更值后解析。
- 空输入和图片粘贴给出文字提示，不再请求旧本地 OCR 工具。
- 配置预览只列出可识别项目及具体警告，不把领袖、纪念物等未提供字段列成导入失败。
- 补上原生单行输入合并两行后，第二行编号不能混入第一行地图说明的解析处理。短种子也不能被误认成下一组编号。
- 一次仍只处理一组；多组或不同编号的种子拒绝混合。
