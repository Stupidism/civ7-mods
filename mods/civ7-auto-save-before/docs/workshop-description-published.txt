[h1]Auto-save Before... · 行动前自动存档[/h1]
过回合前保存 BeforeEndTurn，外交行动前保存 BeforeDiplomacy。两个功能独立开关，保存成功后才继续操作。仅单人游戏本地玩家活动回合。

[h2]更新日志 / Changelog[/h2]
[b]1.1.3 — 2026-11-01[/b]
新增“每回合独立保存”选项，默认关闭。开启后按时代和回合分别保存，如 AutoSave_BeforeEndTurn_00_0050，在“加载游戏 → 自动保存”中查看。关闭后仍覆盖 BeforeEndTurn 固定槽，外交固定槽不变。
New optional per-turn saves, off by default. Files such as AutoSave_BeforeEndTurn_00_0050 use age and turn numbers and appear under Load Game → Autosaves. With the option off, BeforeEndTurn remains a fixed slot. BeforeDiplomacy is unchanged.

[h2]使用方式[/h2]
在“选项 → 附加内容 → 自动存档”设置，右上角“存档”可直达。
同一时代、同一回合重存会更新同名文件；不同战役相同时代和回合也可能覆盖。不会覆盖原版 AutoSave_00_0050 等名称。不承诺永久或无限保留自动存档。固定槽在各单人战役之间共用。
保存失败可重试或取消；游戏禁止保存的阶段，会提示并保留旧备份后继续原流程。外交存档覆盖已支持的战争、合作项目、回应与和平协议等提交入口，仅查看信息不保存。外交结果和影响力成本由游戏规则决定。

[h2]安装与兼容[/h2]
订阅后等待更新并重启，在“附加内容”确认启用。手动安装过同 ID 时先移走 Mods 目录内的重复副本。多人、热座、Autoplay 及非本地活动回合不执行保存。其他模组绕过标准提交入口时需单独验证。
界面跟随游戏语言，支持简体中文和英文。

[h2]验证范围[/h2]
文明 VII 1.5.0 (1311346)，macOS ARM64。86 项离线检查通过。中文实机已验证连续两回合独立保存、自动保存列表、加载返回对应回合、关闭后固定槽；使用原生输入事件及调试接口，不代表实体手柄验收。外交完整往返、英文实机布局、跨时代及长时间存档轮换未在本次重测。封面为功能示意。

[h2]English[/h2]
Save before ending your turn and before supported diplomatic actions. Both main features are enabled by default; the new separate-per-turn option is off by default. Configure them under Options → Add-ons, or use the HUD Saves shortcut.
Per-turn files use a distinct AutoSave_BeforeEndTurn prefix. Saving the same age and turn updates the same file, including matching age/turn numbers in another campaign. Base-game autosave filenames are not overwritten. This is not a promise of permanent or unlimited retention. Fixed BeforeEndTurn and BeforeDiplomacy slots are shared across local campaigns and appear under Load Game → Local.
Actions continue only after successful saving; failures offer retry or cancel. If saving is unavailable at the current stage, the previous backup is retained and the original action proceeds with a notice. Single-player local active turns only. Merely viewing diplomacy does not save. Game-language English and Simplified Chinese UI are supported.
86 offline tests passed. On macOS with Civ VII 1.5.0, Chinese live tests verified two separate turn saves, list visibility, loading, and returning to fixed-slot behavior. Native input events/debug interfaces were used, not a physical controller. English layout, full diplomatic round trips, cross-age behavior and long-term autosave rotation were not retested for this release.
