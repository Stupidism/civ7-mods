[h1]Mac 手柄支持修复 · Mac Controller Support Fix[/h1]
修复 Mac 上 Xbox 手柄能操作《文明 VII》菜单，却无法操作世界地图的问题。左摇杆移动地图光标，镜头可随光标移动；右摇杆平移镜头。

[h2]0.1.5 更新[/h2]
[list]
[*]补充主菜单和轮盘的摇杆连续输入兼容：将菜单中的 HOLD 导航转换为原版可处理的 UPDATE，保留方向与原有焦点规则。
[*]开启“显示调试栏”后，UI.log 会限量记录菜单摇杆输入，方便继续排查；默认关闭。
[*]保留已实测的地图摇杆方向设置及 RB 轮盘功能。
[/list]
[h2]使用方法[/h2]
订阅并等待 Steam 下载，重启游戏，在主菜单“附加内容”确认启用。
[b]Steam 控制器设置请启用 Steam 输入，使用官方 Xbox 布局。[/b]
[b]选项 → 附加内容 → Mac 手柄支持修复[/b] 提供“启用手柄兼容”“翻转左摇杆上下”“翻转右摇杆上下”“显示调试栏”四个开关。确认后保存，取消丢弃修改。原有设置保留；不要同时保留手动版和工坊版。
[h2]操作[/h2]
左摇杆移动地图光标及镜头跟随；右摇杆平移镜头；LT/RT 每次缩放一级；右摇杆按下将光标移回镜头中心。A/B 保留确认和取消。RB 在普通地图打开轮盘；X 保留为备用轮盘按键，选中单位时进入移动选点。Y 执行原生“下一步”，待办完成后可能结束回合。菜单键打开暂停。
[h2]兼容与验证[/h2]
Mac + Xbox 蓝牙手柄已有用户使用反馈，0.1.3 左摇杆方向已获用户实测确认。RB 轮盘可打开已有用户反馈，但菜单左摇杆仍有问题。0.1.5 通过 64 项离线测试，包含原版菜单槽和轮盘连续输入。尚无故障现场的原始输入采样，因此新兼容处理是否解决这次故障仍待手动确认；本次没有开启游戏实测。原版教程或当前视图不允许轮盘时，遵守游戏本身的限制。
城市等 Dual 视图、完整快捷键、其他手柄和多人模式未完成验证。十字键没有连续事件时约 0.75 秒停止，松开再按可继续。原版底部提示可能与此处说明不同。Steam/游戏必须能收到菜单手柄输入；改写同一输入模式的模组可能冲突。
不新增游戏规则或存档实体。测试前完整备份 Saves（包括历史自动存档和 quick），使用测试副本。

[h1]English[/h1]
A compatibility fix for Mac players whose Xbox controller works in Civilization VII menus but not on the world map. The left stick moves the plot cursor and its camera-follow; the right stick pans the camera.
[h2]Version 0.1.5[/h2]
Adds main-menu and radial-panel compatibility for held analog navigation by normalizing menu HOLD samples to UPDATE. Keeps vectors, native focus routing, the working map direction settings and RB shortcut. Debug mode optionally records a bounded set of menu stick samples in UI.log; it remains off by default.
[h2]Setup[/h2]
Subscribe, wait for the download, restart the game, and enable the mod under Additional Content. [b]Enable Steam Input and use the official Xbox layout.[/b]
Open [b]Options → Add-ons → Mac Controller Support Fix[/b] for compatibility, left-stick inversion, right-stick inversion, and the debug bar. Confirm to save or cancel to discard. Existing preferences are retained. Keep only one installation: Workshop or manual.
[h2]Controls[/h2]
Left stick: plot cursor and camera-follow. Right stick: camera pan. LT/RT: one zoom step per press. Right stick click: center cursor. A/B: native confirm/cancel. RB: world-map radial menu. X: alternate radial shortcut, or movement targeting for a selected unit. Y: native next action, which may end the turn. Menu: pause.
[h2]Validation and limits[/h2]
An early version received successful manual feedback with an Xbox Bluetooth controller on Mac; left-stick direction was confirmed working in 0.1.3. RB opening the radial menu was also reported, but left-stick menu navigation still failed. All 64 offline tests pass, including native menu-slot and radial-panel HOLD navigation. The reported failure has no captured raw input trace yet; this compatibility patch still needs manual confirmation. No live game was opened for this update. Native tutorial and view restrictions are preserved.
City/Dual views, full native shortcuts, other controllers, and multiplayer are not verified. D-pad movement expires after about 0.75 seconds without repeated events. Native on-screen hints may differ. The game must already receive menu controller input. Other input-mode mods may conflict.
No new game rules or save entities. Back up the complete Saves directory before testing and use test copies.
