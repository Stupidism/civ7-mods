# 《文明7拯救计划》｜资源规划

资源越来越多以后，分配面板很容易变成一场搬箱子：这座城缺幸福度，那座城想堆科研，骆驼还能再挤几个槽位。「资源规划」把这些重复比较变成明确的分组、倾向和批量分配。它基于 beezany 的 Resource Re-sorts，使用前需要启用这个依赖。

## 1. 城市、城镇和未连接定居点分开看

资源页越长，越难看出哪些地方能接收资源，哪些地方需要的是另一种资源。

定居点按城市、城镇和未连接状态分组，支持折叠；再按金币、食物、科技、文化、生产力或幸福度排序。先找到想解决的问题，再决定资源给谁。

## 2. 先补幸福度，别让资源白白堆过头

有的城已经不缺幸福度，有的城仍在负值。挨个拖资源既费眼，也容易补错地方。

幸福度填充会优先处理城市，再处理城镇；另有只填城镇的入口，不必打乱城市现有安排。目标是补到不为负，而不是把所有幸福度资源都塞给同一个地方。

## 3. 给定居点一个产出倾向

科研城、生产城和缺粮城需要的东西不同。每次打开资源页都重新回忆分工，负担会不断增加。

点击产出图标就能设置该定居点的倾向并分配合适资源，倾向会被记住，也能清除。让长期分工留在界面里，不用每一回合从头解释一遍。

## 4. 一次比较多个定居点的分配

把好资源先塞给列表第一座城，后面真正需要它的地方可能就轮不到了。

“按倾向分配”会一起比较多个定居点的收益和容量，通过匹配与逐步改进安排资源。默认保留已经分配的资源；想全面重排时，再主动打开对应选项。

## 5. 骆驼带来的槽位，也纳入比较

骆驼的价值不只在自身：多出来的槽位，还能装下别的资源。只看单个资源，很容易漏算这一层。

打开“包含骆驼资源”后，规划会考虑扩容带来的后续收益，而不是见到骆驼就塞进去。这个开关默认关闭，需要时再纳入，避免每次打开面板都意外大搬家。

## 6. 调整资源时，列表别突然换位置

刚拖完一个资源，产出变了，定居点跟着重新排序。下一次点击很容易落到另一个位置。

1.1.0 更新让排序集中在打开面板或主动改变排序的时候，分配过程不再因为产出变化自动重排；选中资源时优先执行放置，取消选择与关闭面板也分开处理。这部分交互改动仍按新版验收结果发布。

## 适用范围与进展

核心功能已有工坊版本；本文提到的稳定排序、交互与中英文补齐属于本地 1.1.0 更新范围，发布前需核对最新回执。历史 Windows 1.5.0 实测覆盖分组、倾向、幸福度和骆驼分配，不能代表所有时代与资源 Mod。分配算法会遵守可用槽位和游戏规则，但不承诺全局最优或绝不失败。
