《文明7拯救计划》｜自动存档上限 150

自动存档明明在工作，想回到更早一点的节点时，却发现那份记录已经轮换掉了。「自动存档上限 150」只做一件小事：把原生设置里可选的保留数量上限扩展到 150，让你自己决定留下多少历史。

1. 把自动存档历史留得更长

只保留最近几个节点，适合快速回退，却未必够用来复盘几十回合前的布局。

原生自动存档数量滑块扩展为 1 到 150，按一份为单位调整。你可以沿用原数量，也可以选择更长的历史窗口，不必被迫设到最大。

2. 仍在原生设置里管理

为了改一个数字，再记住一个快捷键或打开额外工具，没有必要。

主菜单和对局中的原生自动存档设置都使用扩展后的范围，确认、取消和保存方式沿用游戏。这个模组不接管存档流程，也不调整存档间隔。

适用范围与进展

当前为 1.0.0 本地版本，目标游戏版本 1.5.0，未发现工坊发布回执。扩展上限不等于自动生成 150 份存档，也不会找回已经被轮换的文件；存档间隔不变。更多存档会占用更多磁盘空间，保留数量和现有存档目录备份是两件事。

Autosave Limit 150 — Civ VII Rescue Project

Autosaves can be working perfectly and still rotate away the checkpoint you wanted. Autosave Limit 150 is a small local mod that expands the native retention slider to 150, leaving the choice of how much history to keep with you. It is not currently presented here as a Workshop release.

1. Keep a longer autosave history

A short retention window works for an immediate undo, but may be too small for reviewing a decision from much earlier.

The native autosave-count slider supports values from 1 to 150 in steps of one. Keep the existing value or choose a longer history; the mod does not force the maximum.

2. Use the existing options screen

Changing one setting should not require a separate tool or another shortcut to remember.

The expanded range is available through the game’s normal autosave options in the main menu and in-game, using native confirmation and persistence. It does not replace the save system or change the interval.

Availability and testing

This local 1.0.0 version targets game 1.5.0; no Workshop release receipt was found. A higher limit does not instantly create 150 saves or recover files already rotated away, and the autosave interval is unchanged. More retained saves use more disk space. Retention is not a substitute for backing up the save directory.

For now, this is a development preview. I would be interested in the situations where you would find it most useful.
