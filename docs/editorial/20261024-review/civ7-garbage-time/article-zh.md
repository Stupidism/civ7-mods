# 《文明7拯救计划》｜垃圾时间

局势已经明朗，待办却还在堆：空槽要补、军队要归队、城市队列又空了。「垃圾时间」把这些可以明确规定的重复劳动交给可选规则，保留需要判断的决定。所有自动化默认关闭，想省哪一步，就只打开哪一步。

## 1. 新到手的资源，按已有分工安排

贸易和回合变化不断带来资源，规划过的定居点又出现空槽，还是要反复打开面板。

启用资源自动化后，每回合按 Resource Planner 中已有的倾向处理资源，并等待游戏允许分配。需要 Resource Planner 和 Resource Re-sorts；默认只动空闲资源，不替你改倾向或发起贸易。

## 2. 让返程部队自己往集合点走

战斗告一段落，分散在地图上的部队还要一个个找路、一个个结束待命。

军队可以前往最近可达的友方定居点，或你指定的目标，抵达后休眠。路径按实际可达性判断；飞机使用游戏允许的转场。它不负责主动进攻或宣战，目标失效时会暂停。

## 3. 增长怎么分配，按你的权重来

定居点越多，重复处理增长的次数越多；只追某一种产出，又可能把幸福度压到危险位置。

可以为增长分配设置全局产出权重，再让个别定居点覆盖它。决策同时检查幸福度门槛，无法可靠读取收益时不提交；不会为了一个看起来更高的数字盲目落子。

## 4. 城市队列空了，用项目接上

主力建筑已经完成，仍要在一座座空队列城市里重复选择项目。

启用后，空队列城市会根据科技、文化权重选择可用项目。现有队列不会被清空；城镇继续原有专精，不会被硬塞进城市项目流程。

## 5. 宝藏船队，带回去再领取

宝藏船队的目的很明确，回港路径和最后一次领取却仍要手动照看。

宝藏自动化寻找最近可达的本土定居点，沿合法路径返航，再使用原生卸载领取奖励。领取会消耗船队，和游戏原有规则一致，因此需要主动开启。

## 6. 传教范围先定好，再执行路线

重复寻找尚未转化的目标很费工夫，但把传教士随便送出国境又不符合每一局的计划。

可以限定自家、城邦或其他势力，默认只处理自家目标。模组寻找可达且仍需要转化的区域，区分城市与乡村，并遵守原生传教资格和次数。

## 7. 给研究空档接上一项

已经进入收尾阶段，还要反复为科技和市政选择下一项，容易变成机械点选。

科技和市政分别开关，优先从可用、未完成的普通项目或精通中选择预计耗时较短的一项，之后才考虑未来重复研究。当前正在研究的项目会保留，不会被强行改掉。

## 8. 幸福度出问题，直接定位处理

帝国很大时，知道有地方不开心，不代表能立刻找到是哪一座城。

幸福度不足提醒可以作为单独功能使用，提供受影响定居点的入口。它提醒你处理问题，不会擅自建造某一座幸福度建筑。

## 适用范围与进展

面向单人游戏，设置按当前玩家、对局和时代隔离；新对局或新时代需要重新选择。不会替你自动结束回合、选政策或处理外交。历史验证主要来自 Windows 1.5.0，当前所有自动化组合、现代场景及完整手柄流程尚未穷举。
