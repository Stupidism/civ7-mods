# 《文明7拯救计划》｜分合

如果时代更替不只是换一套文明，而是让旧世界经历一次真正的分裂与统一，会发生什么？「分合」在做这样的实验：从当前世界出发，模拟版图演变，选择一个历史切片，再挑一个新国家继续玩。它目前是需要本地辅助工具的实验原型，不是即订即用的普通 Mod。

## 1. 让当前世界走向另一种版图

一张熟悉的地图往往对应熟悉的势力边界，想看它经历另一段历史，就得从头想象。

分合从当前世界的定居点和势力出发，模拟分裂与统一。城市位置成为新世界的基础，而政治归属可以重新组合，让“接下来谁统治这里”变成可探索的问题。

## 2. 选择分裂或统一的历史切片

模拟出很多轮变化，最有意思的未必是最后一轮：也许是群雄并起，也许是大国刚刚成形。

可以从模拟结果里选择更分裂或更统一的阶段，把这个切片作为后续场景的基础。不是每次都强制走向同一个结局。

## 3. 换一个国家，在新局势里继续

只看模拟结果像在看地图动画，真正有意思的是亲自接手其中一个国家。

选定一个人类玩家势力后，原型把相应的城市归属、主要国家和城邦关系带入新的时代场景，再进行存档与读档核验。已有样本跑通过这个流程，但仍是有限场景下的实验结果。

## 适用范围与进展

当前 0.2.0-alpha 由游戏模块和界面模块共同组成，还需要本地辅助工具与调试配置。已有 Windows 和 Mac 1.5.0 特定场景的生成、进入新局及读档记录；不是所有地图和时代通用验证。它不是原生时代过渡的完整替代，也不会无损保留人口、巨作、历史、科技和全部军队。
