# 11 月 2 日文明 VII 开发功能统合测试

按悉尼时间核对当天开发记录。环境为 macOS ARM64、文明 VII 1.5.0（1311346）Metal、中文界面、1920×1080 游戏视口。游戏内使用真实原生 UI、地图动作和引擎读回。本轮没有实体手柄输入记录。

共确认两项阻断验收的缺陷。[生产队列点击命中失败 #12](https://github.com/Stupidism/civ7-mods/issues/12) 和 [进入地图后休息计时不再恢复 #13](https://github.com/Stupidism/civ7-mods/issues/13)。

## 范围与构建

定居点 0.2.7、政策 0.2.1、资源 1.4.1 在已安装开发包上临时同步当天的 9 个不同运行文件，实际文件摘要见观测 JSON。完成测试后已恢复原安装。独立行动顺序 0.1.0 用于兼容回归，实际游戏使用三个页面各自提供的行动服务。更好的手柄支持 0.10.0 为组合依赖。另覆盖微操 0.6.3 的对应开发通道、逐回合存档 1.1.3 的对应开发通道及不再来一回合 1.8.7 开发构建。研究转点采用当日独立开发实机证据并重新运行规则和引擎数据回放。神图维持暂停。

## 离线结果

最终 10 个测试组累计 **1,139 项通过，0 失败、0 跳过**。计数按各测试组报告，公共模块与兼容套件可能覆盖相同场景。初轮浏览器路径不匹配及游戏资源路径缺失影响了部分检查；配置匹配的 Chromium、Playwright 和本机游戏资源后重跑了受影响的套件。
