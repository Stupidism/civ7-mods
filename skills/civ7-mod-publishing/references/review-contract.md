# Review contract

每篇最少记录：modId、显示名、sourceVersion、releasedVersion、Workshop URL（如有）、verifiedAt、sourceFiles、validationScope、editorialStatus。

每章记录：feature、claimScope（已发布/本地新版/实验原型）、source、imagePath、imageVersion、imageKind（实机/历史实机/封面/缺失）、caption、missingShotBrief。不能把同一张总览机械铺满每章。

每平台记录：draftPath、title、status（draft/approved/submitted_pending/published/failed/unknown）、approvalScope、url、id、submittedAt、verifiedAt、imageCount、verificationEvidence、contentHash。

审核顺序：
1. 功能对应证据，未完成内容没有写成完成；依赖与限制没有被翻译遗漏。
2. 中文长稿和英文长稿覆盖相同核心功能；Reddit 是短版。
3. 每张图真的展示该章内容，旧图注明历史版本；没有用户隐私、调试窗口或未处理的明显缺陷。
4. 补图清单足够可执行：所需存档/情景、操作终点、画面焦点、可证明什么、不能证明什么。
5. 本地链接只用于审核，外发时换成平台附件/已上传 URL。
6. 未发布 Mod 不提供假下载，已有帖子不重复创建，待审核不标成公开。

批量验收入口显示：全部项目、三份稿件、文字完成情况、配图就绪情况、发布状态、需要用户的决定。完整稿件与制作清单分开，让用户能直接阅读作品。
