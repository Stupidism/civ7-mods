# 测试、实机安全与发行

## 离线优先

- 为缺陷选择真实调用链的可失败用例：输入 → 组件/适配器 → 发出的操作和状态；先证实失败再修复。仅匹配函数名字、只断言模式改变或“没抛异常”不能证明放置/攻击成功。
- 规则测试覆盖容量、合法性、同分保持原分配、幸福度饱和、骆驼净扩槽等本模块约束；设置测试覆盖旧版迁移、共享存储隔离、损坏内容不覆盖、确认/取消。异步覆盖关闭、读档、玩家/回合/时代变化、超时及已提交部分的恢复。
- 性能测试测事件循环能否处理输入，配合结果质量/容量不变检查。避免把一次离线用时当作所有真实地图的速度保证。
- 可读取安装的游戏/依赖源码并在隔离环境回放；不要调用游戏端点。环境依赖缺失的测试明确 skipped，报告通过数与跳过数。
- Node.js 22+；Apple Silicon 核对使用可运行的 ARM64 Node，当前用户 PATH 曾指向 Intel Node。不要为运行测试修改全局 PATH 或覆盖运行时。
- 先运行目标模块 `node --test tests/*.test.mjs` 或其 package.json 的命令（有模块是 `*.test.js`）。根 `node scripts/check.mjs` 检查语法/清单；`node scripts/test.mjs` 汇总多模块。按改动范围选择检查，不为无关改动反复跑全仓库。
- 新文本/清单同时解析 XML、核对文件引用。游戏原生运行库的路径使用项目已有环境变量；独立浏览器使用该测试声明的 Playwright/Chromium 配置。

## 实机或安装前

每次重新读仓库当前 `AGENTS.md` 和锁工具帮助，那里是当前流程的权威；本技能不授权启动测试，也不覆盖用户的停手指令。

1. 明确测试已获用户授权、活动范围、结束条件与可恢复现场。正在玩的正式存档不得当可丢弃 fixture。
2. 启动/重启/加载/保存/推进回合/录制/CDP/UI/替换安装版前按 `scripts/game-lock.py` 申请本会话锁；request 不等于授权，不自行 grant、不抢过期锁。空闲且未暂停时程序自动 FIFO 授锁；其余排队等程序通知，不打断 owner、不唤醒大盘授锁。
3. 持有有效会话/token 后检查所有动作所有权：直接 UI/CDP 前 assert；命令走 lock run 或有锁保护的活动 wrapper。不得手设 `CIV7_GAME_LOCK_GUARDED`。按安全边界 heartbeat（至少每 15 分钟）。
4. 实机交互前完整复制整个 `~/Library/Application Support/Civilization VII/Saves` 到游戏目录、仓库之外的新时间戳目录，包含 auto、auto/prev、quick。逐一核对完整相对路径列表、大小、SHA-256，保存源路径/哈希/备份时间清单；源在复制中变化或验证不完整时停止并解决。只备份最近回合或固定槽不合格。备份不覆盖旧备份；保留原存档、用测试副本。
5. 测其他 Mod 或录制时暂停 Rest Guard 的回合、时间、空闲、夜间限制，核实全部不生效；优先 `scripts/with-game-activity.mjs debug -- <command>` 的显式活动范围。录制入口可能有自动续期 marker，仍需锁与备份。旧版不认识 marker 则按规则显式停用并保留原设置。测 Rest Guard 自身限制时不设 debug 豁免。
6. 原生动作验证实际后置条件，保留版本、平台、样本与证据。录制先居中目标，平滑移动鼠标，点击果断；不把长时间犹豫当平滑操作。
7. 结束前停止并等待所有子控制进程、恢复原 Rest Guard 状态，记录当前游戏/存档状态和备份证据。不要以清理名义删除或覆盖用户存档。
8. 按当前锁协议 release。程序模式由脚本/后台服务自动按 FIFO 授锁，并直接通知下一会话；不要自行转发 notification、mark-notified 或唤醒大盘授锁。排队等通知时可继续独立离线工作。中断时保留锁调查，不释放别人的锁。

## 发行边界

- 清单的游戏/shell 范围、加载顺序、依赖、运行时文件、显示名要匹配。新增数据库规则时审慎判断已有存档/多人兼容；`AffectsSavedGames=0` 不是“这个 Mod 不可能影响存档”的保证。
- 保留第三方代码/图片归属，不复制原版运行库、个人地图、存档、日志、访问令牌或本机调试配置进发行包。包内 `.modinfo` 在正确 Mod 目录第一层，依赖不悄悄打包。
- 版本变更同步实际清单、package/catalog 适用字段与说明；不为了文案任务自行发版。构建发行包后检查完整相对文件列表、大小及哈希。
- 源码修改、压缩包、安装副本、工坊发布分别报告。安装也需要游戏锁；发布必须有明确请求和可审阅文件/文案，不把翻译完成等同已发布。
